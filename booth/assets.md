# BOOTH 出品素材の案

商品ページに載せる画像や、登録時に決める項目の案です。
画像はこのリポジトリに入っているものを使いまわせるように選んでいます。

## 商品画像

BOOTH の一覧や検索結果に出るのは 1 枚目だけなので、1 枚目で「何のアプリか」と「無料で、ブラウザで動く」が伝わるようにします。
2 枚目以降は、README の「スクリーンショット」と同じ流れで、使っている場面を見せます。

### サムネイル（1 枚目）に入れるもの

- アプリのアイコン
- アプリの名前: 「VRChat Worlds Manager Web」
- 一言: 「お気に入りワールドを、フォルダで整理」
- 目立つ札: 「無料」「ブラウザで動く」「PC / スマホ / VR」
- 背景に、VR の中のパネルの写真（`vr-2`）を薄く敷く

### 画像で気をつけること

- **VRChat のロゴは使わない。** 公式のものと見まちがえられないようにする（#162）
- **ほかの人の名前やアバターが写っていないか確かめる。** 招待やインスタンスの画面には、フレンドの名前が出ていることがある。写っていたらぼかす
- 文字は日本語のままでよい。画面の中身を読ませるより、どういう場面かが伝わることのほうが大事
- 1 枚目の文字は、一覧の小さい表示でも読める大きさにする

## 登録時に決める項目

- **価格**: 0 円
- **配布ファイル**: `booth/dist/vrcww-guide-ja.pdf`、`booth/dist/vrcww-guide-en.pdf`
- **カテゴリ**: BOOTH のカテゴリ一覧から、VRChat 向けのツール・ソフトウェアに近いものを選ぶ
- **タグの案**: `VRChat`、`VRChat向け`、`ツール`、`ワールド`、`お気に入り`、`整理`、`PWA`、`XSOverlay`、`無料`
- **年齢制限**: なし（全年齢）
- **説明文**: `booth/description.md` の「説明文」をそのまま貼る

## 出品のあとにやること

- 商品ページの URL を、README（日本語・英語）とアプリの About に載せるかどうか決める
- 配布ファイルを差し替えるときは、`bun run booth:pdf` で書き出し直してからアップロードする。中身の多くは `/guide` にあるので、PDF を直す必要があるのは、あらすじか URL が変わったときだけ
