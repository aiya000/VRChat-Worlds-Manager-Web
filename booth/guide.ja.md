# VRChat Worlds Manager Web 導入手順

VRChat のお気に入りワールドを、フォルダで整理する Web アプリです。
ブラウザで開くだけで使えるので、インストーラーなどはありません。

<p class="url"><a href="https://vrcww.com">vrcww.com</a></p>

## はじめかた

1. ブラウザで **https://vrcww.com** を開きます
2. ホーム画面やデスクトップに追加します（任意）
3. 初期設定をして、VRChat アカウントでログインします

## くわしい手順

端末ごとの追加のしかた、ログイン情報の扱い、VR での使い方、困ったときの連絡先は、次のページにまとめています。
内容はそちらで更新していくので、この PDF より新しい情報はいつもそこにあります。

<p class="url"><a href="https://vrcww.com/guide">vrcww.com/guide</a></p>
